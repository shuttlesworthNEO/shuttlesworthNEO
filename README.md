I build businesses and the engineering behind them. At EmailZap, I lead technical direction, product engineering and the team, and stay hands-on with architecture and code.

### Building EmailZap

- **Zap:** a LangGraph multi-agent assistant using ReAct, tool-calling, persistent state and MCP to answer email questions and act across Gmail and Google Calendar.
- **Personalised memory:** a context layer that uses facts from email history to tailor drafts to the person sending them.
- **Production AI:** golden eval sets, model benchmarking, drift detection and inference efficiency, including System 1 models that filter noise before downstream LLM processing.

### In production

- Took EmailZap from concept to **2,000+ monthly active users**, with **42% week-four retention**.
- Built infrastructure processing **150K+ email updates daily** and cut inference costs by **86%** while maintaining classification accuracy.
- Implemented **PII/SPII pseudonymisation** before LLM processing and achieved **CASA Tier 2 certification** for EmailZap.
